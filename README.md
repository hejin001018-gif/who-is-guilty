# AI审讯室

一个桌面端三人证词推理游戏。案卷、隐藏身份、未公开证据和结案答案只保存在 Node 服务端；浏览器只接收当前已公开的信息。

## 游戏规则

- 三名对象中有 1～3 名罪犯，人物之间可能存在互相保护的关系。
- 调查最多 20 回合，每回合选择一次搜证或审问。
- 整局最多搜证 4 次；服务端会保证四条搜证结果覆盖三名人物的解题证据及一条关系/路线证据。
- 受审讯条例约束，对于未成年人和 70 岁以上老人，围绕该人物最多行动 5 次。
- 玩家可以随时提前结案，但必须完整选中全部罪犯且不能误判无辜者。
- 审问问题必须由玩家自行输入。每名人物保留最近的独立对话记忆。
- 审问画面只展示人物可见的外在表情，且表情可能具有欺骗性，不能作为判断证据；游戏不会向玩家展示或推断人物心理活动。
- 结案后会播放全屏胜负动画，玩家可选择查看包含动机、手法、时间线、人物行为、证据闭环、误导解释和调查全过程的完整复盘，或继续探索新案件。
- 证据中包含事实完全正确、但脱离上下文容易误导判断的物证；证据颜色不会直接提示定罪或排除方向。
- AI 案件导演会参考内置案件结构和最近案卷的推理模式，组合生成多假设、交叉证据、唯一闭环的高难度公平案件。

## 启动

需要 Node.js 20 或更高版本：

```powershell
npm install
npm start
```

访问：

```text
http://127.0.0.1:3000
```

未配置 API Key 时，服务端自动使用内置案件与本地证词逻辑，完整游戏规则仍然可用。

## DeepSeek 配置

复制 `.env.example` 为 `.env`，可只配置一个共享 Key：

```text
DEEPSEEK_API_KEY=sk-your-key
```

也可为案件导演和三名人物分别配置：

```text
GOD_AI_KEY=sk-your-key
AI_1_KEY=sk-your-key
AI_2_KEY=sk-your-key
AI_3_KEY=sk-your-key
```

案件导演默认允许最多 8192 个输出 tokens，以容纳完整 JSON 案卷。需要调整时可在 `.env` 中设置：

```text
DIRECTOR_MAX_TOKENS=8192
```

环境变量优先于兼容保留的 `key.txt`。`.env` 和 `key.txt` 均已加入 `.gitignore`，也不会被静态服务器发布。

如需强制使用本地模式：

```text
DISABLE_AI=true
```

默认只监听 `127.0.0.1`。若主动部署到其他设备，请同时增加正式身份验证、HTTPS 和更严格的持久化限流。
